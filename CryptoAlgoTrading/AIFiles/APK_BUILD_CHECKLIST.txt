❌ "npm not found" or "npm: No such file or directory"
   → Node.js not installed
   → Download from nodejs.org and install
   → Restart PowerShell after installation

❌ "gradle not found" or "gradlew.bat not found"
   → Run: npx cap sync android (first)
   → Ensure you're in: C:\...\CryptoCurrencyScanner\android

❌ "adb not found"
   → Add Android SDK tools to PATH
   → Or use full path: C:\Users\[USERNAME]\AppData\Local\Android\Sdk\platform-tools\adb

❌ "BUILD FAILED" in gradle
   → Check Android Studio console for error details
   → Clear cache: cd android && gradlew.bat clean build

❌ "Cannot find connected device"
   → Check USB cable
   → Enable USB Debugging in device settings
   → Reconnect device

❌ "Installation failed: INSTALL_FAILED_VERSION_OLDER"
   → Existing app has same/higher version
   → Command: adb uninstall com.crypto.scanner
   → Then reinstall

❌ App shows "Mobile (Capacitor)" but jobs don't run in background
   → Check notification permissions in device Settings
   → Disable "Battery optimization" for "Algo Trading" app
   → Check: Settings → Dev Options → Remove project activity limit
