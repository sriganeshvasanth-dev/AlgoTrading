## 📱 Build APK - Step by Step

### **Option 1: Automated Build (Recommended)**

Simply **double-click** `build-apk.bat` in your project root and follow on-screen instructions.

The script will:
1. Install Capacitor packages
2. Build Angular production app
3. Sync files to Android
4. Show you where to find the APK

### **Option 2: Manual Build in Terminal**

1. **Install Capacitor packages:**
   ```bash
   npm install @capacitor/core @capacitor/cli @capacitor/android --save
   ```

2. **Add Android platform:**
   ```bash
   npx cap add android
   ```

3. **Build & Sync:**
   ```bash
   npm run build
   npx cap sync android
   ```

4. **Generate APK:**
   ```bash
   cd android
   gradlew assembleDebug
   ```

APK will be generated at: `android/app/build/outputs/apk/debug/app-debug.apk`

## 🔧 Prerequisites

Before running the build, ensure you have:

### 1. **Android SDK**
   - Download Android Studio from: https://developer.android.com/studio
   - During installation, install Android SDK and Build Tools

### 2. **Java Development Kit (JDK) 11+**
   - Download from: https://www.oracle.com/java/technologies/javase-jdk11-downloads.html
   - Or use OpenJDK 11

### 3. **Environment Variables** (Windows)

   Set these in System Environment Variables:

   ```
   ANDROID_SDK_ROOT = C:\Users\[YourUsername]\AppData\Local\Android\Sdk
   JAVA_HOME = C:\Program Files\Java\jdk-11.x.x
   ```

   (Replace paths with your actual installations)

### 4. **Verify Installation**
   ```bash
   java -version
   gradlew --version
   ```

## 🎯 After Build Completes

### **To Install on Android Phone:**

1. **Enable Developer Mode:**
   - Settings → About Phone → Tap Build Number 7 times
   - Go back to Settings → Developer Options → Enable USB Debugging

2. **Connect Phone via USB**

3. **Install APK:**
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

### **Or use Android Studio:**

1. Open Android Studio
2. Click: Device Manager (bottom right)
3. Create or select an emulator
4. Run: `npx cap open android`
5. Click the green Run button

## 📦 Release APK (For Google Play Store)

The debug APK (created above) only works for testing. For distribution:

1. **Create a keystore:**
   ```bash
   keytool -genkey -v -keystore crypto-scanner.keystore -keyalg RSA -keysize 2048 -validity 10000 -alias crypto-scanner
   ```

2. **Update** `android/app/build.gradle` with signing config

3. **Build release APK:**
   ```bash
   cd android
   gradlew assembleRelease
   ```

APK will be at: `android/app/build/outputs/apk/release/app-release.apk`

## ⚠️ Troubleshooting

### "Gradle build failed"
- Delete `android/` folder
- Run `npx cap add android` again

### "index.html not found"
- Make sure webDir in `capacitor.config.ts` is correct
- Current: `dist/CryptoCurrencyScanner/browser`

### "Android SDK not found"
- Set `ANDROID_SDK_ROOT` environment variable
- Restart terminal/IDE after setting

### "adb command not found"
- Add `%ANDROID_SDK_ROOT%\platform-tools` to PATH
- Restart terminal

### "App crashes on startup"
- Check logcat: `adb logcat | findstr CryptoCurrencyScanner`
- Ensure API endpoint is reachable from mobile
